# EcoFresh Product Passport

## Cara membuka
1. Ekstrak folder `EcoFresh_Product_Passport`.
2. Pastikan `trace.html` tetap berada satu tingkat di atas folder `assets`.
3. Buka `trace.html` melalui browser.

## File
- `trace.html`: halaman Product Passport.
- `assets/`: logo dan foto produk yang dipakai halaman.

## Batch QR
- Batch 01: `trace.html?batch=EF-2026-B01`
- Batch 02: `trace.html?batch=EF-2026-B02`

Data mitra pada halaman ini merupakan data simulasi untuk demonstrasi. Ganti dengan data pemasok aktual sebelum dipakai sebagai informasi ketelusuran komersial.

Catatan: Google Fonts memerlukan internet. Seluruh logo dan foto produk utama sudah disertakan di folder `assets`.
